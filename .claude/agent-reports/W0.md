## What I built
- **Project:** `flutter create` for android, ios, web, windows, macos (org `com.shelfwise`); every MVP dependency added and pinned; `analysis_options.yaml` (strict), `build.yaml`, `l10n.yaml`; the sqflite web binaries (`web/sqlite3.wasm`, `web/sqflite_sw.js`).
- **Core runtime:**
  - `bootstrap.dart` loads the brand, opens the DB for the platform, and shows a readable error screen on config problems.
  - `app.dart`: theme + dark theme + locale from providers.
  - Router with guards and a responsive shell (bottom bar under 600 dp, rail above, extended rail above 1024 dp) with the brand logo and an alert badge.
- **Database:**
  - `db_factory` picks the right sqflite setup per platform (plugin / ffi / ffi-web).
  - `AppDatabase` turns on foreign keys, runs migrations and wraps transactions.
  - `m001_initial` has the full v1 schema, CHECK constraints and indexes.
  - `DbChanges` + `watchQuery` for live queries.
- **Value objects:** `Money` (integer minor units, parsing incl. Arabic digits, percent, rounding steps and modes, margin), `Quantity` (thousandths, unit-aware parsing), `StockStatus`, `DateRange`, `Clock`, `IdGenerator`.
- **Brand system:** `BrandConfig.fromJson` reports every problem at once; `BrandLoader`; `Tier`; `FeatureFlag` covers every gated feature in AGENT_PHASES §4; `FeatureFlags` tier matrix + per-brand overrides + `maxStaffProfiles`.
- **Theme:** brand seed × light/dark; the brand's exact colours are used in light mode, darkened automatically if contrast is under 4.5:1. `StockColors` ThemeExtension with fixed semantic colours. IBM Plex Sans Arabic is bundled and covers Arabic and Latin.
- **l10n:**
  - Per-feature ARB fragments, merged by `tools/scripts/merge_arb.dart`, which enforces prefixes, both locales and no duplicates.
  - Also: `context.l10n`, `failureMessage()`, and `AppFormatters` (money/quantity/percent with a Latin or Arabic-Indic digit choice, local currency symbols).
- **Frozen contracts:**
  - `Result`/`Failure`
  - `Role`/`Permission` + default matrix
  - `SessionReader`/`SessionState` + `FakeSession`
  - Session and preferences provider stubs
  - `AppEvent` + `AnalyticsService` (no-op + recording)
  - `ScannerService`/`NotificationService`/`FileService` + fakes + provider stubs
  - `RoutePaths`, `FeatureRoutes`, guards (`routePermissions`, `routeFlags`, `redirectFor`)
  - Domain entities (freezed) + repository interfaces for onboarding, profiles, categories, products, pricing, stock, alerts, dashboard, import/export and backup
  - Public surfaces (`products/public.dart`, `stock/public.dart`, `alerts/public.dart`, `backup/public.dart`)
- **Stubs:** a placeholder route for every MVP path; a working settings page (theme, language, digits, owner-only links) so G0 can be checked by hand.
- **Sample brands:** `shelfwise` (Aisle, English, EGP) and `demo-green` → "GreenMart Stock" (Shelf, Arabic, SAR), with generated logos and icons.
- **Tests & helpers:**
  - `test/helpers/{test_db,fixtures,test_app}.dart`: in-memory DB, seeded store/branch/profiles/3 categories/20 products, `pumpTestWidget`, `baseOverrides`.
  - Tests for money, quantity, formatters, brand config (including every bundled brand.json), feature flags, contrast, migrations and constraints, guards (owner/staff/locked/no-store/flags/URL entry) and app smoke (boot, RTL, runtime theme/language switch, rail, staff settings).
- **Firebase baseline:** `firebase.json` (two brand targets, SPA rewrite, wasm and cache headers) + `.firebaserc` (dev/prod projects).
- **Dev runner:** `tools/dev_runner.sh` (whitelisted Flutter tasks; used to build this from the sandbox).

## Decisions I made (brief was ambiguous or reality differed)
- **Merged ARBs are committed** (`lib/core/l10n/arb`). `flutter build` requires `generate: true` when `l10n.yaml` exists, and then `pub get` needs the arb dir to exist. Generated Dart (`lib/core/l10n/gen`) stays git-ignored. Docs updated.
- **freezed `4.0.0-dev.3`:** 4.0.1 stable needs analyzer 14, and `riverpod_generator` 4.0.9 is on analyzer 13. **`riverpod_lint` left out** for the same reason. Revisit when both align.
- **Staff can adjust stock** (business plan and TECHNICAL_STRUCTURE §10); the A4 brief said owner-only. The brief is corrected.
- **A1 also owns `lib/core/settings/preferences_impl.dart`** (theme, language, digits, auto-lock persistence). AGENT_PHASES and the A1 brief are updated.
- `AppSpacing`, `AppRadii` and `Breakpoints` are constants rather than ThemeExtensions (they don't vary per brand or theme).
- **Locale priority** is implemented centrally in `effectiveLocaleProvider`: device preference → profile → store → brand default.
- `demo-green` has a clearly different colour, default language (ar) and currency (SAR), so switching brands is obvious in a demo.
- **`openAlertCountProvider` lives in `stock/public.dart`** as the docs say. `AlertBadge` (alerts) reads it.
